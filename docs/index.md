# MattOS Wiki

MattOS is a from-source Linux distribution: every executable, library and
tool it installs is built by the MattOS build system from source kept in one
repository, and it aims for binary package compatibility with Debian 13
(Trixie).

Source code: <https://github.com/HungLo2020/MattOS>

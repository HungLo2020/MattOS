# Utterly-Round-Dark

KDE Plasma Aurorae Themes Theme

## Category: aurorae-themes

## Installation

### Via KDE Store (Recommended)
Download and install via System Settings > Get New [Theme Type]

### Manual Installation
Copy the theme folder to the appropriate directory:

- SDDM Themes: /usr/share/sddm/themes/ (system) or ~/.local/share/sddm/themes/ (user)
- Plasma Look & Feel: ~/.local/share/plasma/look-and-feel/
- Plasma Desktop Themes: ~/.local/share/plasma/desktoptheme/
- Aurorae Themes: ~/.local/share/aurorae/themes/
- Color Schemes: ~/.local/share/color-schemes/
- Kvantum Themes: ~/.config/Kvantum/
- GTK Themes: ~/.themes/
- Icon Themes: ~/.icons/ or ~/.local/share/icons/
- Cursor Themes: ~/.icons/ or ~/.local/share/icons/

## Files Included
- theme-files/ - Complete theme source
- packaged-for-kde-store/ - KDE Store ready package with metadata

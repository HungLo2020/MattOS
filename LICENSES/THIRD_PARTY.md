# Third-party source imports

MattOS imports upstream source code from official repositories and keeps them as ordinary tracked files.

Current configured upstreams:

- Linux kernel: https://github.com/torvalds/linux
- Brush: https://github.com/reubeno/brush
- uutils/coreutils: https://github.com/uutils/coreutils

Each synchronization writes metadata in upstream/state/*.toml.
